You are producing an actions per minute tracker. This tracker should write to a CSV file every minute, on the minute. The CSV file should have two columns. The first should be the number of actions taken in the previous minute, the second should be the epoch timestamp at which the data was recorded.

## Developement Practices
You should develop this project as if it might need to be taken over by someone else at any moment. Use TODO.md to document current incomplete tasks, and use README.md to document current features. Write inline comments frequently. Whenever you finish a task, ask yourself, if someone else picked this project up right now, how could I make their life easier? If there are any easy answers to that question, implement them.
